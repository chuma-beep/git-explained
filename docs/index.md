## The primary rule

A git repository is a graph of commits.
Each commit points to the commit before it.
A branch is a name for one point in the graph.
Most git commands move a name or make a commit.

## The model in the figures

The figures use a railway as the model.
A commit is a wagon.
A branch is a road.
A merge is a junction.

## Technical names in these documents

These documents use the usual terms of git as technical names.
The technical names are `commit`, `branch`, `merge`, `remote`, `rebase`, and `pull request`.
These documents also use the names of the parts of the figures as technical names.
The technical names are `wagon`, `road`, `junction`, `trolley`, `gantry`, `lever`, `desk`, and `barrier`.
